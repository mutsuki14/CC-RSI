After a terminal verdict (PASS, or FAIL when you stop repairing), call learn. It opens a learning phase on
a draft copy of the memory: distill what this experience means for a fresh future agent by editing the
draft directory it names with your file tools, then call memory_commit with the confirmation code from
the stage message. The first memory_commit asks you to reconcile the whole corpus and gives you a new
code; the second promotes the draft. Every stage message carries a fresh code, so read and act on each
stage's instructions before you call memory_commit. A FAIL may still teach, but must never be recorded
as a verified success. UNVERIFIED is not terminal and cannot be learned.
